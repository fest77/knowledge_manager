### 3.1 路由顺序（本模块最容易踩的一处）

`/gaps/aggregate` 与 `/gaps/{gap_id}` **同深度、只差静态段 vs 路径参数**，
必须把静态路径声明在前，否则手动聚合会变成"查一个叫 aggregate 的缺口"。
有用例专门钉住这一点。

## 四、数据模型

E19 `knowledge_gaps`，7 个索引：`normalized_key`（**唯一**）、`status+frequency desc`、
`dept_id+status+frequency desc`、`max_score asc`（"最该补"排序）、
`last_seen_at desc`、`converted_doc_id`（稀疏）、`status+normalized_text`（稀疏）。

**保留策略**：不设 TTL；`open` 且频次归零 → 物理删除；`converted`/`ignored` **永久保留**。

### 4.1 归一化（本模块的核心设计）

六步：NFKC 归一 → 去空白 → **去标点（直接删除）** → 小写 → 去停用词 → 空 key 兜底。
`normalized_key = sha256("{dept_id}|{normalized_text}")[:32]`。

**停用词表的三条硬约束**（写错会造成"错误的合并"，比不合并更危险）：

| 类别 | 处理 |
|---|---|
| 疑问虚词、助词、英文冠词 | **去** |
| **否定词**（不/没/无/未/非/别） | **绝对不去** —— 去掉会把「年假能折现吗」与「年假不能折现吗」合并成一条，语义反转 |
| **程度与数量词**（最/多少/几/上限） | **不去** —— 「上限是多少」问的是数值，「上限」可能是在问规定本身 |

**能力边界**：同义换词（差旅 vs 出差）**规则覆盖不了**，那是 07 的向量聚类职责。

### 4.2 幂等的三重保证

| # | 机制 | 作用 |
|---|---|---|
| 1 | `$set` **重算覆盖**（非 `$inc`） | 重跑不翻倍 |
| 2 | `normalized_key` **唯一索引** + `upsert=True` | 并发/重复只落到同一条 |
| 3 | 进程内**单飞锁** | 两轮并发不互相覆盖（第二轮直接跳过） |

`status` / `converted_*` / `ignored_*` 一律走 `$setOnInsert`：**人工决策优先于机器重算**。

## 六、测试（28 例）

| 覆盖点 | 说明 |
|---|---|
| 归一化 | 标点/全半角/停用词合并；**否定句不合并**；**绝不产出空 key**；部门进 key |
| 识别 | 三种口径 OR 都生成缺口；`faq_hit`/`degraded`/`no_knowledge+denied` **都不算** |
| 合并计数 | 三条同义问法 → 1 条缺口、`frequency=3` |
| 幂等 | 连跑 3 次条数与频次完全不变（AC-08-05） |
| 建议分类 | 众数（按 doc 计票）+ 两级兜底 + `null` |
| 样本 | 最多 5 条且取最近 |
| 人工状态优先 | 忽略后重跑不被改回 `open`；清理只删 `open` |
| 转建 | 全链路（台账 + 任务 + 状态 + `upload_url`）；重复点击无副作用；忽略/过期被拒；04 失败 → 回滚 + 可重试 |
| 复现 | 转建后又被提问 → 频次增长、状态保持、`recurred=true` |
| 清单 | 字段齐全、筛选/排序/`group_by` 跨部门归并、参数码用 `GAP-*` |
| 导出 | BOM + 列名；超上限拒绝 |
| 边界 | 08 不写 `qa_logs`；07→08 投递成功且缺口落库 |
| HTTP | `asker`/`sys_admin` 403；`kb_admin` 全流程；`aggregate` 路由不被吞 |

### 6.1 测试逼出来的三个真 bug

| # | 问题 | 症状 | 修法 |
|---|---|---|---|
| 1 | **批量插入时逐个调 `next_gap_id()`** | 每个候选都拿到 `GAP000001` → 第二条撞 `_id` 唯一索引 → **一次只能产出 1 条缺口** | 加 `next_gap_ids(n)` 一次分配连续编号 |
| 2 | **`find_by_ids` 没投影 `category_id`** | 建议分类永远为 `null`（投票时拿不到分类） | 投影补上 `category_id` |
| 3 | **异步 `aggregate()` 未 await** | `'coroutine' object has no attribute 'to_list'` → 清单 summary 直接 500 | 先 `await` 拿游标再 `to_list()` |

> 第 3 条我在模块 10 踩过一次、这次又踩了一次，所以把原因写进了代码注释。
