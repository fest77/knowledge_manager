## 知识库管理平台

- 项目目标：实现集知识多源维护、四维细粒度权限鉴权、AI 问答鉴权检索、数据运营看板与知识自动沉淀于一体的知识库管理平台，覆盖文档多格式解析切片、全局/部门/角色/个人数据权限控制、未授权安全拦截与溯源、高频 FAQ 聚类挖掘与知识缺口识别
- 交付形式：提供可运行前端控制台、后端业务与检索服务、向量化与大模型适配层、示例知识库测试数据集与端到端问答演示链路

#### 2.9.1 开发范围

- 知识维护与解析：支持单文档上传与批量文档/文件夹拖拽导入（PDF、Markdown、Word、TXT），实现自动化文档清洗、文本分块（Chunking）、语义向量化索引与知识单元生命周期管理
- 组织架构与多维权限：提供用户管理、角色管理、部门树形架构维护，支持菜单/操作功能权限控制与四维混合数据权限（全局公开、部门共享、角色可见、个人专属）
- AI 鉴权检索与问答：实现基于用户登录态的知识检索与鉴权过滤、未授权拦截提示、知识引用溯源卡片、多轮上下文管理与流式 Markdown 渲染输出
- 运营监控与数据看板：统计 Agent 访问量（PV/UV）、知识单元总量、高频提问排行、热门知识单元排行、Token 消耗统计与系统响应延时分布
- 知识自进化与沉淀：实现基于会话日志的高频问题聚类挖掘、候选 FAQ 自动推荐、人工审核发布上线、FAQ 高速缓存匹配加速与未命中知识缺口识别

#### 2.9.2 用户角色与权限

- `普通用户 / 提问者`：登录系统使用 AI 对话工作台进行智能问答，根据被赋予的数据权限获取解答内容，对无权限知识单元接收友好缺失提示
- `知识管理员`：执行文档导入、编辑、切片调整与删除，配置知识单元的四维数据权限，审核并发布推荐 FAQ，查看并处理知识缺口清单
- `系统管理员`：维护组织部门、角色与用户账号，分配功能菜单与按钮操作权限，监控全平台用量看板与模型服务参数

#### 2.9.3 页面需求

- ```
  知识维护与导入中心
  ```

  ：

  - 展示知识单元台账列表（编号、标题、格式、所属分类、权限标签、更新时间、启用状态）
  - 提供单文件上传与批量拖拽导入抽屉，展示文档解析与向量化进度条
  - 提供四维数据权限分配弹窗，支持勾选全局公开或多选部门、角色、人员

- ```
  AI 智能问答工作台
  ```

  ：

  - 提供多轮对话交互界面、智能联想提问与历史会话侧边栏
  - 支持流式打字机渲染、代码高亮、知识引用溯源悬浮卡片与权限缺失安全提示气泡

- ```
  知识沉淀与运营管理页
  ```

  ：

  - `FAQ 挖掘与审核发布区`：展示历史对话聚类产生的高频相似问题推荐列表、聚合频次与参考答案，支持人工在线采纳编辑、发布上线或驳回
  - `已发布 FAQ 知识库区`：管理已发布的标准化 FAQ 问答对，支持问答缓存生效控制与快速检索
  - `知识缺口清单区`：汇总检索未命中或置信度偏低的用户提问、频次统计与时间戳，支持一键转建为知识补充任务

- `运营看板与数据大盘`：展示平台访问量（PV/UV）、知识单元总数、常见高频问题 TOP 榜、高频引用知识 TOP 榜、Token 消耗趋势图与平均响应时长分布

- `组织架构与系统配置页`：维护部门树形结构、用户账号状态、角色功能操作权限树（增删改查、AI访问）与底层模型接口配置

#### 2.9.4 核心鉴权过滤与知识沉淀体系

- 四维混合数据权限规则：
  - 默认状态下知识单元无任何公开访问权限
  - 每个知识单元支持独立配置四类权限实体：`全局（global）`、`部门（department）`、`角色（role）`、`个人（user）`
  - 权限判定采用充分条件（OR 逻辑）：当用户满足配置的任意一个权限实体时即可读取该知识单元
- AI 检索动态鉴权规则：
  - 智能体回答前必须提取当前会话用户身份、直属部门与所属角色集合
  - 混合检索（向量召回 + 关键词检索）产出候选知识单元后，触发数据权限鉴权过滤
  - 仅将满足权限的知识切片拼接至上下文 Prompt 供大模型生成回答
  - 当召回内容包含用户无权访问的知识单元时，在回答中明确标注“部分参考资料因权限受限无法展示”，严禁越权泄漏未授权内容
- FAQ 聚类沉淀与缓存加速规则：
  - 系统对历史提问日志执行语义去重与频次聚合，达到设定阈值自动生成推荐 FAQ
  - 管理员审核通过后打标上线并同步写入内存缓存
  - 新问答优先匹配 FAQ 缓存，命中时毫秒级直接返回标准答案，降低大模型调用开销
- 知识缺口闭环机制：
  - 检索相似度低于置信度阈值或未命中任何知识切片的问题，自动归入知识缺口池
  - 结合提问频次聚合生成知识建设需求，闭环指导知识管理员补充文档

#### 2.9.5 前端模块要求

- `组织与权限管理模块`：处理部门树形控件、用户列表、角色授权树与操作按钮级鉴权控制
- `知识管理与批量导入模块`：处理文件拖拽解析、格式校验、上传进度监听、知识卡片网格与编辑抽屉
- `权限实体选择器`：提供部门树多选、角色多选、人员多选及全局开关的一体化弹窗组件
- `AI 对话交互引擎`：支持 SSE 流式 Markdown 渲染、代码块复制、引用源定位与权限缺失占位卡片
- `沉淀运营与看板模块`：处理 FAQ 审核流转交互、知识缺口转建档、热度排行榜与 ECharts 指标趋势图表

#### 2.9.6 后端模块要求

- `组织与身份鉴权服务`：负责 JWT 登录认证、用户信息解析、部门角色映射与 RBAC 操作权限拦截
- `知识导入与解析服务`：负责多格式文档文本提取、分块分词、多维元数据打标与向量检索库同步
- `动态数据权限鉴权引擎`：接收用户上下文与候选知识单元 ID 列表，执行四维权限过滤并返回放行与受限结果
- `AI 鉴权问答引擎`：协调向量检索、权限裁剪、提示词编排、流式生成与引用溯源元数据组装
- `日志采集与看板服务`：异步记录每轮问答日志（用户、耗时、Token、命中切片），聚合产出运营大盘指标
- `沉淀挖掘与缓存服务`：负责对话日志聚类分析、高频 FAQ 自动生成、知识缺口识别与 FAQ 缓存生命周期管理

#### 2.9.7 核心业务流程

- ```
  知识维护与权限配置流程
  ```

  ：

  1. 知识管理员在导入中心上传单个或批量文档
  2. 系统异步完成文本清洗、切片分割与向量嵌入入库
  3. 管理员打开权限配置弹窗，为知识单元配置全局、部门、角色或人员权限
  4. 权限规则即时生效并同步至鉴权引擎缓存

- ```
  AI 鉴权检索与问答流程
  ```

  ：

  1. 登录用户进入对话工作台输入业务咨询问题
  2. 检索服务执行向量与全文混合检索，召回 Top-K 候选知识单元
  3. 鉴权引擎校验当前用户对各候选知识单元的访问权限，执行权限隔离分流
  4. 聚合有权访问的切片生成严谨回答，并在文末附带知识溯源卡片；对无权单元输出权限缺失受限提示
  5. 异步落库问答流水日志，更新看板统计数据

- ```
  知识沉淀与 FAQ 运营闭环流程
  ```

  ：

  1. 挖掘引擎定期分析问答日志，对高频相似提问进行聚类，自动生成候选 FAQ 推荐项
  2. 知识管理员审核推荐内容，在线修正标准问答并点击发布
  3. 系统将通过的 FAQ 注入快速应答缓存
  4. 挖掘引擎汇总未命中提问生成知识缺口项，知识管理员直接基于缺口创建并补充新知识文档

#### 2.9.8 运营分析与审计输出格式

- `单次问答审计记录`：包含会话 ID、用户 ID、提问时间、提问文本、召回单元列表、鉴权通过列表、鉴权拦截列表、消耗 Token 数与响应耗时
- `FAQ 推荐候选卡片`：包含聚类问题簇、聚合提问频次、关联知识单元、推荐标准答案与置信度得分
- `知识缺口诊断清单`：包含未命中提问文本、提问部门、近期出现频次、最高相似度得分与建议创建分类
- `运营效能指标摘要`：包含当日/当周总提问量、独立提问人数（UV）、FAQ 缓存直接命中率、知识库总覆盖率与平均问答延时

#### 2.9.9 示例业务场景

- `跨部门财务与薪酬制度问答隔离`：财务部导入《差旅报销标准》（权限设为全员公开）与《高管薪酬与股权激励细则》（权限仅设为人力资源部与管理层角色）；普通业务人员提问差旅标准时，系统正常召回并展示答案与来源依据；该人员进一步提问高管薪酬规则时，系统识别其无权限访问对应知识单元，回答中提示“检测到相关制度文档，但您当前所属部门/角色无权查阅该内容”，有效防止敏感数据泄露
- `客服高频退换货问答沉淀为 FAQ 与缺口补足`：一周内多名用户累计提问“生鲜食品破损如何申请退款”超过 50 次，沉淀引擎自动聚类生成候选 FAQ；管理员审核并润色标准应答后发布，后续同类提问全部毫秒级命中缓存直出；同时系统在知识缺口清单中发现“海外直邮保税仓清关延误”提问未命中任何文档，管理员一键创建知识补全任务并导入对应说明文档
- 至少任选一个场景完成端到端全流程演示

#### 2.9.10 验收标准

- 能完成用户登录、部门树维护、角色管理与操作按钮级权限分配
- 能通过界面完成单篇与批量文档导入，并成功将文档解析切片后完成检索入库
- 能对知识单元执行增删改查，并支持混合配置全局、部门、角色、个人四类数据权限
- 能在用户满足部门、角色、个人或全局中任意一种权限时正常访问知识单元
- 能在 AI 对话中强制校验登录态并调用鉴权接口过滤未授权知识单元，对无权限召回项输出明确权限缺失提示
- 能在数据看板正确展示访问次数、独立人数、知识单元数、常见问题榜、知识热度榜、Token 消耗与响应时间趋势
- 能自动从历史对话中挖掘高频问题并生成推荐 FAQ，支持管理员审核发布并写入缓存加速应答
- 能自动识别未命中知识库的问题并生成知识缺口列表，支持查看提问频次
- 能通过至少一个典型业务场景完成端到端全流程问答与沉淀演示
