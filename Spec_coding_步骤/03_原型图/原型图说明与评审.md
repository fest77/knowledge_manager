## 2. 格式与布局依据（沿用 2.3 的逆向结论）

| 项 | 结论 |
|---|---|
| 容器 | 纯 JSON，`{"version":"2.11","children":[...]}` |
| 组件 | 只有 5 种：`frame` / `text` / `rectangle` / `ellipse` / `icon_font` |
| **布局语义** | **省略 `layout` = 横向排列（row）**；`"vertical"` = 纵向；`"none"` = 绝对定位（**子节点必须带 x/y**） |
| 尺寸 | 整数，或 `"fill_container"` |
| 字体 | `Inter`（正文）/ `Funnel Sans`（品牌与数字）/ `IBM Plex Mono`（代码与字段名） |
| 图标 | `icon_font` + `iconFontFamily: "lucide"` |
| 约定 | 每页底部保留「关键需求标注」区块 |

## 6. 本次评审发现并修复的问题

### 问题 1（真遗漏）：原型 02 缺了整个筛选工具栏与上传按钮【我造成的】

`fCate` / `fStatus` / `fPerm` / `btnUpload` 在生成文件里**命中 0 处**——我把筛选工具栏 `filt` 定义了却**忘了加进 body**。
**已修**：补入 body，内容校验从 19/23 变为 **23/23 全绿**。

### 问题 2（跨项目共性缺陷）：`layout="none"` 的用法错误 —— **2.3 也有，已一并修**

我把并排布局的页面写成 `layout="none"`（绝对定位模式），但 shell 的 `sidebar` 与 `main` **都没有 x/y** → 在老师的工具里**会全部叠在 (0,0)**。

对比老师原文件可确认：`layout:"none"` 的子节点**都带 x/y**（如 `后台菜单 x=0 y=0`、`主内容区 x=204 y=28`）；而**省略 `layout` 的容器子节点才是并排**（`后台导航 240px` + `主内容 fill_container`）。

**已修**：
- 2.9：5 个 shell 型页面改为省略 `layout`；弹窗 `mask` 补 `x=0,y=0`；矩阵页改 `vertical`
- **2.3：6 个 shell 型页面同样修正**（回头修的，因为属于已交付产物）
- 两个项目的校验器都补上了「布局语义」检查规则，锁死这类问题

### 问题 3（遗留）：三处破坏性操作缺二次确认

- 05 的「驳回候选 FAQ」「重建缓存」
- 07 的「停用用户」「重置密码」

**低保真阶段可接受，需在 Step 4 模块 Spec 的异常处理章节明确要求。**
